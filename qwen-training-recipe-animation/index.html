Tailored Training Recipe

Understand optimizer roles, token batches, scaling-law experiments, and why fewer steps need careful interpretation.

Training is a long series of workshop adjustments. Different tools suit different parts. Taking measurements in larger groups can reduce the number of adjustments, but does not mean fewer objects were measured.

What an optimizer changes

Backpropagation supplies gradients: directions associated with changing loss. An optimizer converts them into parameter updates. AdamW tracks moment estimates and applies decoupled weight decay. Muon uses a matrix-oriented momentum update with an approximate orthogonalization step. Different tensor roles can benefit from different update rules.

Why split weight categories?

A two-dimensional weight matrix and a small normalization vector have different structure. An optimizer assignment should respect those roles and the actual training recipe. We do not infer the exact category mapping from the model-card summary. A toy assignment exercise is a design illustration, not a reproduction of Qwen training.

Batch size is not learning rate

A token batch is how many tokens contribute to one optimizer update, possibly accumulated over multiple microbatches and devices. A batch-size warmup starts with smaller batches. A learning-rate warmup starts with smaller step sizes. Removing one does not establish that the other is absent.

Scaling laws guide, experiments decide

A scaling law is an empirical fit relating training choices and outcomes. Changing the architecture can change that relationship. Refitting means running experiments and estimating a new useful regime. Starting with a large target batch may reduce updates at fixed token count, while each update contains more work. Compare validation loss, processed tokens, wall time and stability together.

Worked example

For a toy 1,024-token run, batch 64 requires 16 updates. Batch 256 requires four. Both process 1,024 tokens. In a two-phase illustration, 512 tokens at batch 64 plus 512 at batch 256 requires 8 + 2 = 10 updates. These numbers isolate accounting, not convergence quality.

Gated Residual

Understand widened residual streams, element-wise reads, and scalar writes with small vectors.

A shared workspace has several notebooks. A read gate controls which details a worker takes from a notebook; a write gate controls how strongly the worker adds the result back.

Open the interactive chapter, exercises and questions

Why keep a residual path?

In a simple residual layer, x_next = x + F(x). The layer adds a learned correction while preserving a direct path for the old representation. This helps information and gradients travel through a deep network. The residual stream is the representation passed between layers, not a collection of independent answers.

Read and write have different jobs

A read gate scales features before the transformation sees them. An element-wise gate can admit one coordinate strongly and another weakly. A write gate scales a branch update before it is added back. A scalar applies the same multiplier across that branch update. These controls are not interchangeable.

What widening adds

Multiple residual branches provide more channels for carrying information across depth. Learned mixing, normalization and projections connect this wider state to sublayers. Our two-coordinate experiment isolates one branch and sets F to the identity so you can do every multiplication by hand; it is not the full architecture.

Stability is a training property

A zero write gate preserves the old value in our toy. This illustrates how updates can be moderated, but does not prove that all real gradients remain bounded. Gate initialization, normalization, optimizer settings and training data still matter. A small gate value also does not mean the sublayer computation was skipped.

Worked example

Take x = [2, 4], read r = [0.5, 0.25], and write w = 0.5. Read: r ⊙ x = [1, 1]. Transform: identity leaves [1, 1]. Write: [0.5, 0.5]. Add the residual: [2.5, 4.5]. The two read multipliers differ; the write multiplier is shared.

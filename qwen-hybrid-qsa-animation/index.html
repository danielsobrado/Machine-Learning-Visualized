Hybrid Attention with QSA

Combine a compact running memory with selective access to micro-blocks of earlier tokens.

Imagine reading a long case file. A running notebook preserves the broad story. When you need an exact number, an index sends you to a few short passages in the original file.

Start with ordinary attention

A token is one piece of text. A query represents what the current position needs; keys help find relevant positions; values carry information to combine. During decoding, reading a growing cache of earlier keys and values can cost substantial memory bandwidth. During prefill, computing attention for many prompt positions also adds work.

Two complementary ways to remember

A recurrent state is a compact running summary: update it as tokens arrive instead of re-reading every old token. This is efficient, but a compressed state may lose exact details. Sparse attention offers another path: choose some old context and read its detailed representations. Hybrid layers let the network use both kinds of access.

Select a block, then use its tokens

A lightweight indexer identifies useful small groups of adjacent tokens. Fetching groups can be friendlier to hardware than fetching isolated positions. Selection is sparse; the computation within selected context can still use individual token keys and values. Micro-block selection does not mean replacing every group with one output token.

Separate a saving from a speedup

An estimate of tokens read omits indexer work, cache layout, projections, memory bandwidth and the other layers. Fewer reads can help without making end-to-end time shrink by the same factor. A selection mistake can also hide the evidence needed for a correct answer. Compare quality and measured time at the same context length.

Worked example

Toy example: 32 visible tokens form eight blocks of four. Selecting two full blocks loads eight token positions: 25% of the dense read count. This is a 4× reduction in this count, not a measured 4× speedup. A causal mask must still exclude future positions inside a boundary block.
